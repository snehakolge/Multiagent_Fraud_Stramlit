# 🏦 EFRMS – Enterprise Fraud Risk Monitoring System

## 📌 Overview
EFRMS is an AI-powered Fraud Detection and Risk Monitoring system designed to simulate real-world banking fraud monitoring operations. It uses machine learning (XGBoost) to detect fraudulent transactions and provides real-time risk alerts, case tracking, and compliance-ready insights inspired by RBI guidelines.

---

## 🚀 Key Features

### 🔍 Fraud Detection Engine
- XGBoost-based classification model
- High accuracy fraud prediction
- Threshold-based risk scoring

### ⚡ Real-Time Alert System
- Instant fraud flagging
- High-risk transaction alerts
- Velocity & behavioral anomaly detection

### 📊 Risk Analytics Dashboard
- Fraud trends visualization
- Feature importance analysis
- Transaction behavior insights

### 🧠 Explainable AI (Optional Upgrade)
- SHAP-based model interpretability
- Reason codes for fraud decisions

### 🏛️ Compliance Alignment
- RBI Early Warning Signals (EWS)
- AML monitoring logic integration
- Fraud pattern tracking
